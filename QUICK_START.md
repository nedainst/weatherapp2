## 🚀 QUICK START GUIDE

### Langkah-Langkah Cepat (3 Menit)

#### 1️⃣ Daftar API Key (2 Menit)
```
Kunjungi: https://openweathermap.org/api
Klik: Sign Up (free)
Isi form registrasi
Login ke akun Anda
Buka: Your API keys
Copy API key (huruf panjang di sana)
```

#### 2️⃣ Setup (30 Detik)
- Buka file: `script.js`
- Cari baris: `const API_KEY = 'YOUR_OPENWEATHERMAP_API_KEY_HERE';`
- Ganti dengan API key Anda
- Simpan file (Ctrl+S)

#### 3️⃣ Jalankan (30 Detik)
- Buka `index.html` di browser
- ATAU gunakan Live Server di VS Code

### ✅ Done! Aplikasi Siap Digunakan!

## 🔧 Troubleshooting Cepat

**Q: Error "API key tidak valid"**
A: Tunggu 10 menit setelah mendaftar, API key baru butuh waktu aktivasi

**Q: Tidak bisa cari kota**
A: Pastikan format nama kota benar, coba gunakan bahasa Inggris

**Q: Blank/Putih saja**
A: Check console (F12), lihat error message di sana

**Q: Loading terus**
A: Periksa internet, atau API limit tercapai (tunggu sebentar)

## 📱 Akses dari HP

1. Jika menggunakan Live Server: Copy URL dari browser
2. HP harus 1 network dengan komputer
3. Paste URL di browser HP
4. Done! Akses weather app dari HP

Contoh URL: `http://192.168.1.xxx:5500/`
